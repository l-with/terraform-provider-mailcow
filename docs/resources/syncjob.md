# mailcow_syncjob (Resource)

Provides a syncjob in mailcow.
This can be used to create, modify, and delete syncjobs.

Requires mailcow 2026-11 or later: the IMAP server a sync job copies mail from is
a sync source (`mailcow_syncjob_source`), referenced by `source_id`.

## Example Usage
```terraform
resource "mailcow_syncjob_source" "example" {
  name = "example.com"
  host = "imap.example.com"
}

resource "mailcow_syncjob" "syncjob" {
  username  = "demo@440044.xyz"
  source_id = mailcow_syncjob_source.example.id
  user1     = "demo@example.com"
  password1 = "secret-password"

  custom_params {
    option = "errorsmax"
    value  = "100"
  }
}
```

## Migrating from `host1`, `port1` and `enc1`

mailcow 2026-11 moved the IMAP server of a sync job into a sync source and migrated
existing sync jobs to sources automatically. `host1`, `port1` and `enc1` were removed,
and `custom_params` changed from text to a list of `option`/`value` blocks.

1. Update mailcow to 2026-11 or later.
2. Replace `host1`, `port1` and `enc1` with `source_id`: either a new `mailcow_syncjob_source`
   or the source mailcow created during its migration, imported with
   `terraform import mailcow_syncjob_source.<name> <id>`.
3. Write `custom_params` as blocks, for example `--errorsmax 100` as
   `custom_params { option = "errorsmax" value = "100" }`.

The state of existing sync jobs is upgraded on the next plan and `source_id` is read
from mailcow. With the imported source the plan shows no change for the sync job;
with a new source it shows an in-place update that moves the sync job to it.

## Schema

### Required

- `password1` (String, Sensitive) the password of the mailbox on the host (--password1)
- `source_id` (Number) the id of the sync source (e.g. `mailcow_syncjob_source.source.id`) with the IMAP server mails are synced from
- `user1` (String) user to login on remote host (--user1)
- `username` (String) user to login on local host (--user2)

### Optional

- `active` (Boolean) is sync job active or not
- `automap` (Boolean) try to automap folders ("Sent items", "Sent" => "Sent" etc.) (--automap)
- `custom_params` (Block List) custom imapsync parameters; mailcow only accepts the options of its allowlist (see [below for nested schema](#nestedblock--custom_params))
- `delete1` (Boolean) delete (mail) from source when completed (--delete1)
- `delete2` (Boolean) delete messages on destination that are not on source (--delete2)
- `delete2duplicates` (Boolean) delete duplicates on destination (--delete2duplicates)
- `exclude` (String) exclude objects (regex) (--exclude)
- `maxage` (Number) only sync messages up to this age in days (--maxage)
- `maxbytespersecond` (String) max speed transfer limit for the sync (--maxbytespersecond)
- `mins_interval` (Number) the interval in which messages should be synced (minutes)
- `skipcrossduplicates` (Boolean) skip duplicate messages across folders (first come, first serve) (--skipcrossduplicates)
- `subfolder2` (String) sync into subfolder on destination (empty = do not use subfolder) (--subfolder2)
- `subscribeall` (Boolean) subscribe all folders (--subscribeall)
- `timeout1` (Number) timeout for connection to remote host (--timeout1)
- `timeout2` (Number) timeout for connection to local host (--timeout2)

### Read-Only

- `id` (String) The ID of this resource.
